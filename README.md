# WpeRemix

Wallpaper Engine 场景资源提取与静态 PNG 合成工具，适用于 Windows x64



## 使用

- 启动 `WpeRemix.exe`，将多个 PKG、TEX、ZIP 或壁纸文件夹拖入任务区
- 点击整个处理队列的空白区域添加资源，工具栏也保留文件和文件夹入口
- 选择窗口中可用 Ctrl / Shift 多选文件、文件夹，点击“添加所选项”直接加入队列；双击文件夹或使用“打开文件”仍可进入目录浏览
- 导入选择窗口默认打开 Wallpaper Engine 创意工坊壁纸目录
- 固定同时合成 PNG 并提取原始素材，无需选择导出方式
- 默认保存到系统 Downloads 文件夹，支持自选并记住其他目录
- 保存位置与开始处理位于同一操作栏
- 拖入提示仅在队列为空时出现，添加后让出整个队列区域
- 空队列提示覆盖整个内容格，采用无边框空态与中性灰白反馈，图标操作支持悬浮提示和键盘焦点
- 预览不添加黑色内底，报告紧随图片，适配横图和竖图，隐藏滚动条并保留滚轮和键盘滚动
- 状态和进度在各任务内展示，底部不弹出全局提示，布局保持固定
- 使用 Windows 原生深色标题栏，最小化、最大化、关闭和悬浮反馈由系统处理
- 每项独立显示进度和结果，可预览、打开图片或结果文件夹
- 未选择任务时隐藏详情，待处理任务只显示一次来源路径，生成结果后再显示结果操作
- 点击任务路径会用资源管理器打开对应文件夹
- 同名输出自动另存，不修改输入包；取消会停止当前项目，已完成结果保留



## 合成范围

- 读取场景画布、图层顺序、父子关系、位置、缩放、平面旋转、透明度和基础颜色
- 保留原始场景分辨率，不自动放大，不通过 AI 重绘
- PNG 使用无损编码；源图本身的 JPEG 或 DXT 压缩损失无法恢复
- 动态滤镜、脚本、粒子、文字、时钟、音频条和特殊混合不参与原图合成
- 骨骼素材使用默认纹理姿态，可能与播放中的画面不同
- 动画 TEX 当前仅保留原文件，不转换动画容器；普通 GIF 图片可取第一帧合成
- 3D、透视、视频或缺失依赖的场景可能无法合成，已提取资源仍保存在 assets 文件夹
- 不支持的图层和效果写入处理报告，带提示的结果需要对照原场景检查
- 单张图像最多一亿像素，单边最多 32768 像素，避免异常资源耗尽内存



## 开发

- C# / .NET 10 / WPF，无外部 UI 库
- 使用 .NET 10 SDK 构建，Windows x64
- `build.ps1` 发布常规便携目录；`build.ps1 -Standalone` 发布包含运行时的目录
- 可传入 `-DotnetPath` 指定便携 SDK 中的 dotnet.exe
- 业务输入与输出只在用户指定目录处理，中间文件使用独立临时目录
- 无遥测、无账号登录，转换过程离线运行
